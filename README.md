# СтройРасчёт

Веб-приложение для предварительных строительных расчётов, изучения формул, ведения проектов и составления смет.

## Первая версия
- Адаптивный минималистичный интерфейс для компьютера и телефона.
- Калькуляторы объёма бетона, площади стен, количества блоков, расхода штукатурки, площади пола, кровли и утеплителя.
- Формулы и объяснения.
- Сметы с количеством, единицами измерения и ценами.
- Печать сметы или сохранение в PDF через браузер.
- Локальное сохранение проектов и смет в LocalStorage браузера.

## Запуск Windows
1. Установите Python 3.10 или новее: https://www.python.org/downloads/
2. Скачайте репозиторий через Code → Download ZIP и распакуйте.
3. Запустите run.py двойным нажатием или командой py run.py.
4. Откройте http://127.0.0.1:8000.
5. Для остановки нажмите Ctrl+C в окне терминала.

Сторонние Python-пакеты не нужны.

## Файлы
- index.html — интерфейс и логика приложения.
- run.py — локальный HTTP-сервер.
- README.md — инструкция.

## Ограничения
Расчёты являются предварительными оценками. Проверяйте фактические размеры, проектные решения, технологические требования и рекомендации производителей. Приложение не заменяет инженерный расчёт ответственных конструкций.
